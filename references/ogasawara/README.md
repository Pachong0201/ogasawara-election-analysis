# 小笠原方法参考说明

本目录存放与 `ogasawara-election-analysis` 方法脉络相关的阅读笔记、来源记录与操作化说明。

## 定位

- 本目录不是复制或翻译任何单一著作。
- 所列方法是从公开研究、公开访谈与公开评论中提炼出的分析框架，经工程化后用于台湾选举结构分析。
- 具体事实仍须回到中选会、地方选委会、学术研究与可靠公开资料。

## 方法要点

1. 长期历史资料优先于单次选举。
2. 以行政区层级矩阵观察选举结构，而不是只看全国总票。
3. 注意总统、立委、地方首长与政党票之间的跨层级差异。
4. 先发现异常，再查找地方政治、派系、组织与候选人经营资料。
5. 地方政治关系有时间范围，不能自动外推当前。
6. 不以单一民调或单一事件形成确定结论。
7. 输出应说明证据、机制与不确定性。

## 使用限制

- 不得将本目录内容写成对真实人物的政治评价。
- 不得声称某事实来自小笠原欣幸，除非有明确、可查证来源。
- 新增来源时必须记录作者、标题、年份、出处、链接与访问日期。
- D/E 级资料不得写入本目录的“已验证事实”。
