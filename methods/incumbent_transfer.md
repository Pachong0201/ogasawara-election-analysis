# Incumbent Transfer：现任交棒分析

## 目的

当现任县市长无法或不再参选时，单独分析其政治基础、组织与票源是否可能转移给接班人。核心原则：

> 现任支持不等于接班支持。

## 必须比较

| 项目 | 说明 |
|---|---|
| 现任者上届得票 | 县市长选举得票率与乡镇市区分布 |
| 本党总统票／政党票 | 同地区同期基准 |
| 现任满意度 | 必须注明调查机构、日期、方法与题目 |
| 接班候选人支持度 | 必须注明调查来源与未决定比例 |
| 现任者是否公开站台 | 记录日期、场合、来源 |
| 地方公职是否跟随 | 议员、乡镇市长、里长等公开动态 |
| 竞选组织是否移转 | 竞选总部、服务处、组织干部是否转入 |
| 原政治网络是否继续支持 | 必须有近期公开资料验证 |

## 分析顺序

1. 建立现任者历届选举在乡镇市区的得票矩阵。
2. 比较本党总统票、政党票与县市长票差距。
3. 检查现任满意度民调的方法与题目。
4. 检查接班人是否曾任公职、经营同一地区、拥有独立组织。
5. 检查地方公职与组织的公开支持。
6. 判断哪些票源可能随现任者转移，哪些可能流失或重新分配。
7. 明确无法验证部分。

## 解释边界

- 不得把现任满意度直接转换为接班人支持度。
- 不得把现任者高票直接视为接班人基本盘。
- 不得把地方组织公开站台直接等同于组织票。
- 接班人个人残差必须单独计算。
- 第三势力票和对手结构变化必须独立分析。

## 输出建议

> 现任者上届在甲、乙两乡表现较强，但本届接班人是否继承该结构，取决于竞选组织是否移转、地方公职是否公开支持、接班候选人自身经营，以及本党总统票与政党票在该地区的分布。现有资料能确认现任者历史基础，但不足以直接推算接班得票。
