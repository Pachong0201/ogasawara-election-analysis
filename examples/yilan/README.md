# 宜兰试点测试资料

本目录只用于 `ogasawara-election-analysis` 的验收测试，不是 Skill 运行依赖。删除本目录后，Skill 仍必须能分析其他县市。

## 测试定位

宜兰只承担三项作用：

### Test A

验证跨层级选举矩阵能否发现地方／全国差异。

### Test B

验证历史派系资料是否会被错误外推到当前。

### Test C

验证 Skill 能否从数字异常自动触发地方知识检索。

## 资料说明

本目录不预填任何未经核实的宜兰历史选举数字、派系名称或人物关系。验收测试以问题输入、应执行步骤和通过标准为主。若未来加入资料数据，必须：

- 标明来源等级与日期；
- 区分历史 `time_scope` 与当前 `last_verified_at`；
- 不得将历史派系自动外推当前；
- 不得把测试用合成资料写成真实选举事实。
